# 任务型协议：运维 / 迁移 / 批量操作

## 完成定义

1. **先数后动**：`COUNT`/`SELECT` 拿到影响面数字 → dry-run → 执行 → **复核同数**。
2. **影响面写清**：`IMPACT: 影响 <对象范围>，备份 <路径>`（第 5 条）。
3. **回滚方案**：能一键回去（git / 备份文件 / 快照），并说明怎么回去。
4. **收尾核验**：端口空、进程净、数据条数对得上。

## 3 个检查点

- **CP1 只读探测先跑**：任何破坏性操作前，先跑一条只读命令确认目标存在且范围正确。
- **CP2 禁后台分离执行**：`rm -rf`、批量替换、`DROP` 不许丢到后台跑（出事没人接）。
- **CP3 通配先展开**：`rm -rf $dir/*` 先算展开结果；变量为空或解析到盘符根 → 立即停。

## 常见翻车

| 翻车 | 症状 | 正确做法 |
|---|---|---|
| 变量为空 | `rm -rf /` 灾难 | 展开后校验非空 + 非根 |
| 范围算错 | 删了不该删的 | 先 COUNT，交付时复核同数 |
| 后台执行 | 命令挂掉无人知 | 前台跑，或后台但记 PID 并轮询一次 |

## 退出条件

影响面数字前后一致 + 回滚点已留 → 交付；数字对不上 → 立即停并报告差异，不要"再跑一次试试"。
